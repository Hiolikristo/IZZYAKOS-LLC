# Studio quality

Capture quality comes before AI enhancement.

- Camera at eye level; consistent headroom.
- Soft key ~45 degrees; weak fill; separate subject from background.
- Prefer a real branded set. If virtual, use segmentation/matting confidence, temporal edge smoothing, spill suppression and foreground/background color-temperature matching.
- Image automation: face-aware exposure, white balance, mild denoise, local contrast, skin-tone protection, highlight recovery.
- Audio: close mic, noise suppression, high-pass, gentle compression, target web speech around -16 LUFS, true-peak limit about -1 dBTP.
- Guests: green room, host admit/mute, per-guest gain, echo cancellation and connection quality.
- Treat Zoom as an input/source, not the final compositor.
