# IZZYAKOS BroadcastKit · original read-only adapter v0.1

This is independently authored integration code, **not** a replacement for AzuraCast or a production radio server. `npm test && npm start` (Node.js 20+) starts an unauthenticated read-only status API on port 8787; `/healthz` and `/api/stations/jericho-hour/now-playing` are available. Without an actual server the endpoint truthfully returns `demo-unconfigured`. After approval, provision a separate Linux AzuraCast server with HTTPS, set a vetted `apiOrigin` and its public numeric station ID in `stations.example.json`, and restart. Never put admin API keys in the browser or public JSON. Add per-tenant authentication, fixed upstream allowlists, secure media storage, rate limiting, auditing, load tests and permission/rights workflows before commercial release. AzuraCast remains AGPL-licensed; honor its source-sharing requirements for applicable combined software. The product opportunity is the original installation wizard, themes, station orchestration, archive/rights ledger and paid support—not reselling an existing open-source engine as proprietary.
