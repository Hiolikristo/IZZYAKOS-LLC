# Jericho Hour Radio & Community Network — GitHub microsite

Owner-review demonstration on the `jericho-hour-radio-demo` branch, kept separate from the company production branch. Site folder: `jericho-hour-radio-demo/`. `index.html` contains the radio/website proposal and real browser-generated demo tone. `studio.html` has a self-contained *simulation* of station mode and local schedule editing. It is **not** a live broadcast server. The complete richer PWA build, official user-supplied raster logo, MP3 sample, working static application and proposal PDF are provided separately in the packaged deliverables from the same ChatGPT conversation; they are not mirrored in this minimalist microsite. Before full production, set up a dedicated AzuraCast server, grant approved presenter access, verify music rights and owner-approved sermon master files, and enable real CMS/booking integrations.

Deployment: use the complete ZIP and `deploy-netlify.ps1` to publish into existing Netlify project `4591ae61-5079-4eca-b6d3-403f260516e2`. Do not assume a GitHub commit automatically deploys the Netlify project.
